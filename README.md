# From-Growth-to-Profit-Uncovering-Where-an-Ecommerce-Business-Wins-and-Loses-Value
This project is an interactive three-page Power BI dashboard that analyzes the performance of a multi-channel European ecommerce business across 2024 and 2025. It goes beyond revenue reporting to answer a harder question: is growth actually turning into profit, and where is value being lost?
